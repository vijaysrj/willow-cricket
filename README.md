# Willow — 3D Cricket

<img src="icon-512.png" width="96" alt="Willow icon">

A 3D T20 batting game for people who read scorecards for fun.

**Play:** https://vijaysrj.github.io/willow-cricket/

- Chase a target in a Super Over, a 5-over chase or a full T20
- Swipe to play drives, cuts, pulls, flicks and glances; tap to defend; toggle Loft to go aerial
- Match centre with scorecard, wagon wheel, pitch map, Manhattan and worm, timing analysis and a saved career record
- Wicket huddles, milestone celebrations, fireworks for sixes and a floodlit night match in dark mode

Single HTML file, built with three.js.
